# 📊 Delhi NCR Sales Analysis | SQL Project

## 📌 Project Overview
A SQL-based analysis of Delhi NCR sales data to understand business performance, customer behaviour, product sales, profitability, and delivery operations.

## 🎯 Objectives
- Analyse overall sales and profit.
- Track monthly sales trends.
- Compare category, city, and sales-channel performance.
- Identify top products, customers, and sales representatives.
- Review order status, delivery time, and customer ratings.

## 🛠️ Tools Used
- Microsoft SQL Server
- SQL Server Management Studio (SSMS)
- SQL (T-SQL)

## 🔍 Analysis Performed
1. Overall business KPIs
2. Monthly sales and profit
3. Category performance
4. City-wise performance
5. Sales-channel analysis
6. Order-status analysis
7. Top 10 products
8. Sales representative performance
9. Delivery time and customer ratings
10. Top 20 customers

## 💡 SQL Concepts
`SELECT`, `WHERE`, `GROUP BY`, `ORDER BY`, `DISTINCT`, `TOP`, aggregate functions, `ROUND()`, and `NULLIF()`.

## 🚀 How to Run
1. Open SQL Server Management Studio.
2. Create and select the `DelhiNCRSalesDB` database.
3. Import the dataset into the `SalesData` table using the column structure in the SQL script.
4. Open and execute `SQL_Analysis.sql`.
5. Review the query results to identify business insights.

> **Note:** The dataset is not included. Import your data before running the analysis queries. Update any local file paths in the script to match your system.
